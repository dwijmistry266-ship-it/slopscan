# slopscan

**AI slop detector for your codebase.** A static-analysis CLI that scans Python files for the low-quality patterns AI-generated code leaves behind — placeholder stubs, dead code, sycophantic comments, hallucinated APIs, copy-pasted blocks — and reports a **slop score (0–100)** per file plus a repo summary.

Zero dependencies. Stdlib only. Installs in seconds.

## Install

```bash
pip install slopscan
```

Or from source:

```bash
git clone https://github.com/dwijmistry266-ship-it/slopscan
cd slopscan
pip install -e .
```

Requires Python 3.9+.

## Detectors

| Detector | What it flags | Severity |
|---|---|---|
| `placeholders` | TODO/FIXME/XXX/HACK comments; "implement later" promises; `...` / `pass`-only / `NotImplementedError`-only function bodies | info–bad |
| `deadcode` | Unreachable code after return/raise/continue/break; unused imports; unused local constants | info–warn |
| `comments` | Sycophantic comments ("great", "perfect", "amazing"); comments that restate the code; commented-out code blocks | info–warn |
| `overengineering` | Functions over 60 lines; nesting deeper than 4; single-use `_private` helpers; classes with only `__init__` + one method | info–warn |
| `hallucinations` | Names called or used but never defined/imported/assigned in the file (skips star-imports, builtins, string annotations) | bad |
| `duplication` | Near-duplicate blocks ≥6 lines (identifiers/literals normalized), 15+ lines rated bad | warn–bad |

Every detector is AST/tokenize-based and **conservative by design** — a false positive is worse than a miss. Each module's docstring documents exactly what it checks and where it stays silent.

### Scoring

- Finding weights: `info` = 1, `warn` = 3, `bad` = 10.
- File slop = `min(100, 100 × weight / lines_of_code)` — density-based, so long files aren't punished for length.
- Repo slop = lines-weighted mean of file scores. **Cleanliness** = `100 − slop`.

## CLI

```
slopscan [path] [--format term|json|md] [--min-severity info|warn|bad]
         [--fail-under N] [--ignore PATTERN] [--no-color]
```

- `slopscan .` — scan recursively (skips `.git`, `venv`, `__pycache__`, hidden dirs).
- `slopscan --format json src/` — machine-readable output.
- `slopscan --format md src/` — Markdown report.
- `slopscan --min-severity warn` — hide info-level nits.
- `slopscan --fail-under 80` — exit 1 when repo cleanliness drops below 80. **Built for CI.**
- `slopscan --ignore "test_*" --ignore "generated/*"` — skip paths by glob.

## CI usage

```yaml
- run: pip install slopscan
- run: slopscan --fail-under 80 .
```

slopscan dogfoods itself: this repo's CI runs `slopscan slopscan --fail-under 90` on every push — the tool must score its own codebase clean.

## Agent-skill usage

`slopscan/skill.md` is a ready-made skill definition for AI coding agents. Point your agent at it and add one line to its loop:

> After writing or generating Python code and before committing, run `slopscan --format md` on the changed files. Fix every `bad` finding; consider each `warn`.

## Project layout

```
slopscan/
  __init__.py        # __version__ = "0.1.0"
  __main__.py        # python -m slopscan
  cli.py             # argparse interface
  registry.py        # detector registry + runner
  findings.py        # Finding record
  scoring.py         # severity weights, 0–100 scores
  reporters.py       # term / json / md reporters
  skill.md           # agent skill definition
  detectors/
    placeholders.py  # TODOs, .../pass stubs, not-implemented
    deadcode.py      # unreachable code, unused imports/locals
    comments.py      # sycophantic / restating / commented-out
    overengineering.py  # long fns, deep nesting, thin classes
    hallucinations.py   # used-but-never-defined names
    duplication.py      # near-duplicate blocks
tests/               # 84 tests, positive + negative cases per detector
examples/sloppy_sample.py  # deliberately sloppy demo file
```
